# 架构与安全边界

## 技术边界

- 桌面壳：Tauri 2；后端命令与系统能力使用 Rust。
- 前端：Vue 3、TypeScript、Vite；富文本编辑器使用 TipTap 3。
- `src/App.vue` 负责应用级状态和跨组件编排；可复用视图在 `src/components/`。
- `src/types.ts` 是前端领域类型入口；`src/ai.ts`、`src/settings.ts`、`src/storage.ts` 封装 Tauri 调用和浏览器调试回退。
- `src-tauri/src/lib.rs` 注册命令；`library.rs` 管文档，`settings.rs` 管设置和 Key，`ai.rs` 管 AI 请求与流式响应，`models.rs` 管 Rust 数据类型。
- 新增跨边界字段或命令时，同步 TypeScript 类型、Rust 模型、命令注册、调用参数和兼容默认值。

## 本地文档

- 用户选择的文档根目录是内容唯一持久化位置；默认位于系统“文档/拿了桔子跑啊”。
- `.mojian-library.json` 保存知识库结构与稳定文档 ID 到文件路径的映射。
- 每篇文档是普通 `.md` 文件，首行的 `mojian-meta` 注释保存 ID、知识库、父子关系、回收站、置顶、标签和时间信息。
- 回收站使用 `deletedAt` 软删除。永久删除、知识库删除及清单收敛属于高风险路径，修改时必须覆盖恢复和误删场景。
- 保留旧版 `notes.json` 读取以及前端可选字段归一化兼容边界，不用一次性破坏性迁移替代它们。
- 目录切换必须先把当前完整 Store 写入新目录，成功后才能保存新路径。写文件继续使用临时文件加重命名，避免半写入。
- 保持路径清洗、相对路径校验、数量和大小限制；不得允许绝对路径、`..` 或不受控文件名越过文档根目录。

## AI 数据隔离

- 每次请求都必须携带非空 `documentId`，只包含当前文档标题、正文、当前选区和用户本次要求。
- Rust 系统提示必须继续明确唯一文档边界，并把文档正文视为不可信资料，防止正文中的提示注入覆盖系统约束。
- 对话、写作、标题、标签和选区工具不得从全局笔记集合拼接其他文章。
- 保留上下文长度限制、连接超时、总超时、HTTP 状态压缩错误以及流式/非流式兼容。
- 前端使用 Tauri Channel 接收流事件；不要把 AI HTTP 调用和密钥放到 WebView 前端。

## 设置与密钥

- `settings.json` 位于 Tauri 应用数据目录；AI Key 单独保存在 `ai-api-key` 文件，不进入设置 JSON。
- Unix 下 Key 文件权限保持 `0600`。当前方案不使用系统钥匙串，避免额外的系统密钥访问授权弹窗。
- 前端只接收 `hasApiKey`，不得把已保存的明文 Key 回传到界面。
- 永远不要记录请求 Authorization、完整 Key、私钥内容或包含用户文档的调试转储。
- `.gitignore` 必须继续排除 `.env*` 的真实配置、`*.key`、`*.key.pub`、证书、签名文件和构建产物；示例环境文件只能包含占位值。
- 发现工作区存在被忽略的密钥时，不读取、不移动、不删除，也不因为“修复 CI”而提交。先使用文件名和 Git 跟踪状态判断风险。

## 内容安全与兼容

- AI 或 Markdown 生成的 HTML 必须经过现有净化边界后再渲染，不放宽 DOMPurify 或链接安全限制来解决样式问题。
- 用户文档、设置目录和回收站内容都按不可替代数据处理。涉及格式迁移时先设计回滚、备份或双读兼容，并补充 Rust 测试。
- 保留桌面端与浏览器调试回退的差异：真实文件、系统对话框和 AI 只在 Tauri 中承诺完整能力。
