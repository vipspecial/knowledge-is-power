# 拿了桔子跑啊项目维护

在本仓库内实现修改时，保留既有产品方向、数据安全和发布约束。先检查当前代码和工作区状态；本 Skill 是维护基线，代码中的更新事实优先，但发现不一致时必须说明并同步修正 Skill。

## 开始工作

1. 读取 [产品与界面规则](references/product-rules.md)。
2. 涉及 Vue、Tauri、编辑器、AI、设置或文档存储时，再读取 [架构与安全边界](references/architecture-safety.md)。
3. 每次完成修改前都读取并执行 [版本、验证与发布](references/release-quality.md)。
4. 查看 `git status`，保留用户已有或无关修改，不覆盖、不回滚。

## 核心约束

- 产品名固定为“拿了桔子跑啊”，英文副标题为 “Knowledge is power”。界面文案、文档和提交信息使用简洁中文。
- 编辑器保持单区所见即所得；Markdown 是存储与导入导出格式，不恢复源码/预览分栏。
- AI 按当前文档隔离上下文，入口跟随标题、选区、正文和对话场景，结果统一进入当前文档右侧会话并流式展示。
- 文档坚持本地优先，保存在用户指定目录。任何迁移都必须先保证旧数据可恢复，不做静默破坏性变更。
- API Key 和签名私钥不得进入 Git、日志、测试快照或回复内容，也不得读取、打印、提交或上传被忽略的密钥文件。用户文档不得进入 Git、日志或测试快照，除非用户明确要求，否则回复中不复述其正文。
- 应用内自动更新已启用：更新私钥只存本地 `.tauri/`（已被 Git 忽略）和 GitHub Secrets，公钥内嵌在 `src-tauri/tauri.conf.json`；未经用户明确要求不更换密钥对、不更改更新端点。
- 不主动推送分支、创建或推送标签、发布 Release、部署 Pages；这些外部操作必须由用户明确授权。

## 实施原则

- 组件只负责展示和交互；跨模块状态编排留在现有应用层，文件、设置和网络能力经 Tauri/Rust 边界实现。
- 优先扩展现有类型、组件和命令，不复制第二套编辑、存储、AI 或设置流程。
- 修复问题时检查同一区域的滚动、折叠恢复、尺寸调整、空状态、右键菜单和窄窗口表现。
- 只在能解释复杂意图、安全边界或兼容逻辑时增加注释，避免复述代码。
- 若本次决策改变了本 Skill 中的长期事实，在同一提交内更新对应参考文件。

## 完成交付

- 按项目规则同步版本和 `CHANGELOG.md`，执行与改动风险匹配的检查。
- 每个完成的修改都创建一次中文 Conventional Commit。
- 向用户说明结果、版本、验证情况和提交号；存在未验证项时明确指出。
