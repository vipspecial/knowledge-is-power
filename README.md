# 拿了桔子跑啊

一款以 AI 辅助创作为核心、本地优先的 Markdown 笔记应用。支持 macOS、Windows 和 Linux。

名字源自范伟电影台词中对 **Knowledge is power** 的趣味谐音：“拿了桔子跑啊”。我们借用这份幽默，也希望知识不只被收藏，更能随手带走、马上用起来。

## 核心能力

### AI 写作

- 生成文章、标题、大纲和标签
- 续写、改写、校对和总结全文
- 润色、精简、扩写、翻译和解释选区
- 针对当前文档问答并分析内容缺口
- 流式输出，可替换、插入或追加结果

### 知识管理

- 多知识库与父子文档
- 搜索、标签、置顶和文档副本
- 卡片与紧凑列表模式
- 回收站与文档树恢复

### Markdown 编辑

- 编辑、分栏、预览三种模式
- 编辑区与预览区双向同步滚动
- 支持 GFM、任务列表、引用、代码和链接
- 导入和导出 Markdown

## 适用场景

| 场景 | 用法 |
| --- | --- |
| 长文创作 | 用 AI 生成大纲、续写、校对和优化表达 |
| 工作记录 | 整理会议纪要、周报、方案和行动项 |
| 学习研究 | 管理读书笔记，并针对当前内容提问 |
| 项目知识库 | 用知识库和父子文档划分不同项目 |

## 快速开始

1. 在左侧创建或选择知识库。
2. 新建文档，直接使用 Markdown 编写内容。
3. 切换到分栏模式，边写边看预览。
4. 在设置中配置 AI 服务。
5. 从标题、选区、正文或右侧助手调用 AI。

## AI 使用

AI 功能分布在对应的写作位置：

| 目标 | 入口 |
| --- | --- |
| 生成标题或标签 | 标题和标签右侧 |
| 优化一段文字 | 选中文字后出现的工具栏 |
| 续写或校对全文 | Markdown 工具栏 |
| 从零起草文章 | AI 写作工作台 |
| 总结或询问文章 | 右侧 AI 助手 |

首次使用时，前往“设置 → AI 助手”填写 API 地址、模型和 API Key。支持 Chat Completions、Responses API 及兼容服务；Ollama 等本地服务可不填写 Key。

## 文档与数据

- 文档以真实 `.md` 文件保存，可自行备份或同步。
- 默认目录为系统“文档/拿了桔子跑啊”，可在设置中修改。
- 删除的文档先进入回收站，可恢复或永久删除。
- AI 默认关闭，仅在主动调用时发送当前文档或选区。
- 不同文档的 AI 上下文相互隔离。
- API Key 保存在应用配置目录，不使用系统钥匙串。

## 界面操作

- 知识库栏、文档栏和 AI 栏均可折叠。
- 文档栏、编辑区和 AI 栏可调整宽度。
- 右键知识库、文档或回收站条目可快速操作。
- `Cmd/Ctrl + N`：新建文档
- `Cmd/Ctrl + F`：搜索
- `Cmd/Ctrl + S`：保存
- `Cmd/Ctrl + J`：AI 写作
- `Cmd/Ctrl + ,`：设置
