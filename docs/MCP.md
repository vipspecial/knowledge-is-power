# MCP 使用说明

“拿了桔子跑啊”内置通用只读 MCP，可被任何兼容 MCP 的工具接入。

## 接入

1. 打开“设置 → MCP”。
2. 开启“启用 MCP”。
3. 点击“复制安装信息”。
4. 把安装信息粘贴给支持 MCP 的 AI，或导入其 MCP 设置。

不需要选择客户端、打开终端或手动查找路径。应用会自动准备当前系统和文档目录所需的信息。

## 可用能力

| 工具 | 作用 |
| --- | --- |
| `list_knowledge_bases` | 列出知识库及文档数 |
| `search_documents` | 搜索标题、正文和标签 |
| `read_document` | 按文档 ID 读取一篇文档 |

## 安全边界

- MCP 默认关闭，只能在应用设置中单独开启。
- 仅开放当前文档目录，目录变化后授权会同步更新。
- 只读正常文档，不返回回收站内容，也不能创建、修改或删除文件。
- 不读取或复制 AI API Key。
- 关闭开关后，已经安装的 MCP 连接也会失效。

如果连接失败，先确认应用中的 MCP 开关仍然开启，并重新复制一次安装信息。
